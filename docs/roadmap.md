# Forge Roadmap

## 0.1.0

- Typed personalized token sets for Android and iOS.
- Accessible custom primitives and core mobile selection/progress components.
- Shared component showcase, automated verification, and Maven Central publication.

## Later

Chips, badges, overlays, pickers, and form orchestration begin in consuming applications and move
into Forge only after product-agnostic reuse is demonstrated.
